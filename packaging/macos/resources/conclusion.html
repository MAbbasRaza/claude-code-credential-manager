Installed. Open Claude Code Accounts from your Applications folder, or run ccm in a Terminal.

Adding your first account

Your accounts are added by capturing the one you are already signed into:

ccm add work

Then sign into your other account in Claude Code as usual and run ccm add personal. After that, ccm use work switches back with no browser involved.

Capture an account before you sign out of it. Signing out destroys the refresh token, and nothing can recover it afterwards except signing in again.

Start at login is not switched on by this installer, because the installer runs as the system rather than as you. Turn it on from the desktop app's Settings, or run:

ccm autostart enable

To uninstall, run sudo ccm-uninstall. Your saved accounts are kept unless you remove them yourself.
