This installs Claude Code Accounts, a tool for switching between Claude Code accounts without signing in again.

Claude Code stores one account's credentials at a time. Signing into a second account destroys the first account's refresh token, so going back means a full browser sign-in. This keeps each account's credentials in a protected vault and swaps them back on demand, which makes switching an offline, one-second operation.

What gets installed

  • Claude Code Accounts in your Applications folder, a window for adding, switching, renaming and removing accounts.
  • ccm, the command line tool, available in any Terminal.
  • Claude Code Accounts Menu Bar, an optional menu bar icon for switching without opening anything. You can leave this out on the next screen.

An administrator password is required, because these install into /Applications for every user on this Mac.

Your existing Claude Code setup is not touched. Only the two account-scoped keys move during a switch; MCP server logins, project history and settings are left exactly as they are.
